# Hôpital Bel-Alzette Fire Board

A demonstration emergency information board for a hospital fire, with a zoomable 3D floor plan, evacuation status and field reports.

The hospital, its address, phone numbers and all figures are fictional.

Live page: https://2v4vw2z4gt-netizen.github.io/bel-alzette-fire-board/

Field reports sent on this page are kept only in the visitor's own browser session.
